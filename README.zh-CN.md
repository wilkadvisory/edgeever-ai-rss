# EdgeEver AI RSS

[English](README.md)

这是 [EdgeEver](https://github.com/tianma-if/edgeever) 官方插件。

以 AI 为核心的 EdgeEver RSS / Atom 日报插件。它使用 EdgeEver 工作区已经配置的默认 AI Provider，将精选订阅按主题整理成日报并直接保存为笔记。

## 功能

- 新安装默认启用 60 个来源：AI 前沿 41 个、开发与开源 10 个、中文阅读 9 个。AI 来源覆盖官方实验室、每日简报、研究分析、实践者写作、中文机器学习与深度访谈；科学与研究、产品与设计、商业与创业、安全与隐私仍是可选主题。升级时保留已有主题选择。
- 通过“探索和管理 RSS 订阅”命令搜索并订阅 5 个精选中文来源（阮一峰、云风、潮流周刊、小众软件、张鑫旭），以及随插件内置、可离线搜索的 1,260 个中文独立博客公开 HTTPS 来源。也可手动更新目录、添加最多 30 个自定义公开 HTTPS RSS / Atom 源并指定主题与内容语言。订阅前会验证所选源；精选与个人订阅分开显示，取消订阅不会删除已有日报。目录中已纳入 60 个默认信源的条目随其主题启用，其他目录源默认未订阅。
- 并发读取精选 RSS / Atom 并缓存最近文章；单个订阅源或 AI 请求失败不会阻止其他分类继续生成。跨来源事件聚类会折叠规范化链接、规范化标题及高置信度相似标题，同时保留全部佐证来源。
- 保存日报后，对入选文章的标题与摘要按设置的目标语言小批量翻译；缓存的译文可在下次生成时复用。关闭自动翻译后不会产生这部分 AI 调用，单批翻译失败也不会阻断日报。
- 按所选主题分别生成 RSS 日报，默认汇总最近 24 小时，标题采用 `YYYY-MM-DD · 分类 · RSS 日报`（随日报语言本地化）；正文以元信息卡片开篇，直接呈现 7 至 10 个以 `## 01 | ...` 编号的独立热点与分割线排版，每个热点包含带加粗重点的简短要点和独立行信源链接。候选不足时不会为凑数而重复或虚构热点。候选文章会按规范化链接和标题去重、覆盖当前可用的来源角色，并限制单一来源占比后再交给 AI。同日同分类再次生成时更新原笔记，没有新内容的分类会跳过。每个有内容的主题通常调用一次 AI；若输出额度不足，可能缩小额度后重试一次。
- 可由用户明确开启桌面端自动日报，并按设备时区从 24 个整点中选择生成时间；默认关闭，界面会在启用前说明 AI 调用方式，也可随时暂停。
- 通过 EdgeEver 官方声明式插件设置页统一配置订阅主题、自动日报时间、日报时间范围和单分类文章上限；每个主题提供「查看信源」入口，由 EdgeEver 以列表展示其内置信源名称与站点域名，布局、校验、响应式与保存状态由 EdgeEver 统一提供。
- 不注册独立阅读页面；手动或自动生成的日报直接写入工作区笔记本，优先沿用已有目标笔记本，否则使用首个笔记本。
- 设置页、命令、订阅面板、提示和错误信息跟随 EdgeEver「通用 → 界面语言」，提供简体中文、英语和日语（其他语言回退到英语）。「日报与翻译语言」设置决定日报的写作语言（简体中文、繁体中文、英语、日语或韩语），默认跟随界面语言。
- Provider、模型和凭据完全由 EdgeEver 管理。

## 订阅源

运行“探索和管理 RSS 订阅”命令，在精选、中文独立博客和我的订阅之间切换。社区目录来自 [timqian/chinese-independent-blogs](https://github.com/timqian/chinese-independent-blogs) 的 MIT 许可 OPML 快照，内置于插件以便离线搜索；快照日期见 [生成文件](src/community-directory.ts)，许可证见 [第三方许可](LICENSES/chinese-independent-blogs-MIT.txt)。可手动读取上游最新目录，部分旧地址可能失效。点击订阅只验证所选源。内置基础信源仍可通过设置中主题旁的“查看信源”查看。目录中已内置的信源会显示为已包含，其余需要另行订阅；订阅源仅在对应主题启用时参与日报。个人源上限 30 个，可能增加读取耗时和 AI 消耗。自动日报仍默认关闭，须用户明确开启；使用默认主题手动生成时，通常最多有 3 次按主题生成的 AI 调用，每个主题遇到输出额度不足时最多重试一次；开启翻译后还会产生翻译调用。请仅添加无需账号或令牌的公开订阅源。

## 开发

```sh
bun install
bun run check
bun run check:feeds # 可选：在线检查内置订阅源健康状态
```

构建会生成 EdgeEver 所需的 `main.js` 与 `styles.css`。发布 GitHub Release 时，应将它们与仓库根目录的 `manifest.json` 一同上传，并确保版本与标签一致。

插件要拿的是发布方自己的内容。有公开 RSS / Atom 就直连；没有一手 feed 的发布方会自动尝试免费公共 RSSHub。请求经 EdgeEver 匿名只读公网传输，不携带 Cookie、账号凭据或敏感请求头。单个源失败不会挡住其他来源。
